Виберіть, як ви запускаєте Kept, і пройдіть його кроки. Для кожного шляху є повний посібник у цьому
розділі; посилання в кінці його кроків.

## Щось не працює?

- **Контейнер постійно перезапускається.** Прочитайте його журнал: `docker compose logs kept`.
  Kept перевіряє свої налаштування до запуску і зупиняється з рядком, що називає першу проблему,
  наприклад `kept: invalid environment: KEPT_PUBLIC_URL` (виконайте
  `docker compose run --rm init`). Якщо `docker compose up -d` зупиняється на `bootstrap`,
  `docker compose logs bootstrap` каже чому. Коли пам'яті менше за 1 ГБ, резервному копіюванню
  може її забракнути, і Docker перезапускає Kept ([що потрібно](/uk/install/hardware/)).
  [Докладніше](/uk/admin/troubleshooting/#kept-завершується-при-запуску-з-kept-invalid-environment--або-іншим-рядком-kept)
- **Порт зайнятий.** Kept займає порт 8080 на хості. Виконайте `docker compose run --rm init`
  ще раз з адресою `http://` на вільному порті: він записує адресу і порт (`KEPT_HTTP_PORT`) у
  `.env`. Потім `docker compose up -d`. У додатку Home Assistant змініть порт у
  **Конфігурація → Мережа** і вкажіть нову адресу в опції **Власна адреса Kept**.
  [Докладніше](/uk/install/compose/#1-запишіть-env)
- **Відмовлено в доступі.** Kept працює від користувача 10001 з файловою системою лише для читання,
  тож тека, яку ви в нього монтуєте, наприклад каталог для резервних копій, має належати uid 10001.
  `init` записує `.env` у теку, з якої ви його запускаєте: запускайте його у власній теці.
  [Докладніше](/uk/admin/troubleshooting/#бекапи-не-запускаються-або-спрацьовує-сповіщення-backup-stale)
- **Інші пристрої не відкривають його.** `localhost` відкривається лише на цій машині. Візьміть
  ім'я, яке знаходять інші пристрої, задане в DNS вашого роутера або у файлі hosts кожного
  пристрою, і виконайте `init` ще раз із ним. Якщо Kept каже «Цей Kept налаштовано для *адреса*.
  Відкрийте його там.», відкрийте його саме за цією адресою або додайте іншу в
  `KEPT_EXTRA_ADDRESSES` ([більше ніж одна адреса](/uk/install/home-network/#більше-ніж-одна-адреса)).
  [Докладніше](/uk/admin/troubleshooting/#цей-kept-налаштовано-для--або-the-request-did-not-come-from-this-site)
- **502 від зворотного проксі.** Kept говорить звичайним HTTP на порті 8080: спрямуйте проксі на
  `http://`, а не `https://`, на цьому порті
  ([за зворотним проксі](/uk/install/reverse-proxy/)). Kept запускається лише після завершення
  `migrate`; якщо воно не вдалося, `docker compose logs migrate` каже чому.
  [Докладніше](/uk/admin/troubleshooting/#kept-не-запускається-після-оновлення-а-migrate-завершився-з-помилкою)

Усе інше: [Усунення несправностей](/uk/admin/troubleshooting/).

## Далі

- **HTTPS:** він потрібен камері, встановленню застосунку, push-сповіщенням і геолокації.
  [Поставте Kept на HTTPS](/uk/install/https/), або [Kept у домашній мережі](/uk/install/home-network/)
  про те, що працює без нього.
- **Асистент:** питайте простими словами, з вашим власним провайдером ШІ; Kept працює і без нього.
  [Провайдери ШІ](/uk/users/ai-providers/) і
  [Підключити клієнта штучного інтелекту (MCP)](/uk/users/mcp-clients/).
- **Резервні копії:** щоночі й зашифровані, у каталог, S3 або SFTP.
  [Резервні копії](/uk/admin/backups/).
- **Пошта:** скидання паролів, запрошення й нагадування поштою, з `KEPT_SMTP_URL` і
  `KEPT_SMTP_FROM`. [Пошта, Push-сповіщення та стрічка календаря](/uk/admin/notifications/).
- **Home Assistant:** інтеграція приносить те, що настає, на панелі та в автоматизації.
  [Home Assistant](/uk/users/home-assistant/).

## Оновлення

- **Docker Compose:** вкажіть новий реліз у `KEPT_IMAGE` в `.env`, потім:

  <Code code={commands.compose.update} lang="sh" />

  Реліз, що змінює `compose.yaml`, каже про це у своїх примітках: завантажте його файл поверх
  вашого.
- **З вихідного коду:**

  <Code code={commands.source.update} lang="sh" />

- **Kubernetes:** кожен реліз публікує чарт тієї самої версії, і його міграції виконуються в Job,
  перш ніж нова версія почне обслуговувати.
- **Proxmox VE:** `update` у консолі контейнера. Він спершу питає і повертається назад, якщо нова
  версія не запускається.
- **Home Assistant:** Home Assistant пропонує оновлення. Увімкніть
  **Keep backup of the last version** у його діалоговому вікні оновлення.
- **Unraid:** вкладка **Docker** пропонує оновлення: **apply update**.

Коли задано ціль резервного копіювання, Kept робить знімок перед міграцією.
[Оновлення та відкат](/uk/admin/upgrades/).
