---
title: Початок роботи
description: "Короткий шлях від нуля до вашої першої речі в Kept, з посиланням на повну сторінку для кожного кроку."
---

Короткий шлях, по одному кроку в рядку. Кожен крок посилається на сторінку з подробицями.

1. **Встановіть.** Docker з плагіном Compose; перевірено на 1 ГБ оперативної пам'яті та одному ядрі процесора.
   Завантажте `compose.yaml`, потім `docker compose run --rm init` (він запитує адресу, за якою ви відкриєте Kept, і записує `.env`) і `docker compose up -d`. Репозиторій копіювати не потрібно, і паролі створювати не треба. [Встановлення за допомогою Docker Compose](/uk/install/compose/)
2. **Заявіть сервер.** Відкрийте адресу, введіть код налаштування, який показав `init`, і створіть перший
   обліковий запис: він стає адміністратором екземпляра.
   [Прив'язати сервер](/uk/users/first-run/#1-отримайте-сервер-за-допомогою-коду-налаштування)
3. **Збережіть ключі.** Роздрукуйте набір відновлення і тримайте його поза сервером.
   [Набір для відновлення](/uk/admin/recovery-kit/)
4. **Створіть свій перший дім.** Назва, його вид, його кімнати та набір для того, що він відстежує.
   [Створіть свій перший будинок](/uk/users/first-run/#3-створіть-свою-першу-головну)
5. **Додайте річ.** **Сканування** на телефоні або **Додати сюди** в кімнаті чи коробці на комп'ютері.
   [Додайте свою першу річ](/uk/users/first-run/#4-додайте-свою-першу-річ)
6. **Запросіть когось.** Посилання або QR-код із роллю (адміністратор, учасник або глядач); адреса електронної пошти нікому не потрібна.
   [Запросити людей](/uk/users/first-run/#5-запросіть-людей)
7. **Увімкніть HTTPS**, щоб телефони дозволяли камеру, встановлення Kept, офлайн-використання та push-сповіщення.
   [HTTPS](/uk/install/https/), або [Kept у домашній мережі](/uk/install/home-network/) для того, що працює
   без нього
8. **Підключіть ШІ**, якщо хочете: Kept працює і без нього. [Провайдери AI](/uk/users/ai-providers/)

Далі: [Щоденне використання](/uk/users/everyday-use/) для огляду, [FAQ](/uk/users/faq/) для поширених
запитань і [Поширені проблеми](/uk/users/troubleshooting/), коли щось не працює.
