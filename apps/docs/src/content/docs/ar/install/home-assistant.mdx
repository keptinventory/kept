يُشغّل Kept كتطبيق لـ Home Assistant: Kept وقاعدة بياناته الخاصة في تطبيق واحد، على نظام Home Assistant OS. لا Docker Compose، ولا كلمات مرور لإنشائها، ونسخ Home Assistant الاحتياطية تضمّه.

## تطبيق Home Assistant أم تثبيت عادي؟

نفس Kept، نفس الإصدار، نفس الميزات: الأشياء، الأماكن، الخريطة والرسم البياني، المسح، التسميات، الذكاء الاصطناعي، MCP، الاستيراد، Paperless، عدة أشخاص.

| | تطبيق Home Assistant | [Compose](/ar/install/compose/) أو [Kubernetes](/ar/install/kubernetes/) |
|---|---|---|
| يفتح | الشريط الجانبي في Home Assistant، وعنوان Kept الخاص (المنفذ 8080) | عنوان Kept الخاص |
| التثبيت، التحديث | متجر تطبيقات Home Assistant | `docker compose`, `helm` |
| الحساب الأول | يضبط مسؤول Home Assistant دون رمز | رمز الإعداد من سجل Kept |
| الإعدادات | علامة تبويب **التكوين** في التطبيق | `.env` أو قيم المخطط |
| بدون اتصال، تثبيت تطبيق الهاتف، الإشعارات الفورية | عنوان Kept الخاص عبر https؛ ليس في الشريط الجانبي | عبر https |
| مفاتيح المرور، OIDC، Google | عنوان Kept الخاص (https لمفاتيح المرور؛ https واسم نطاق عام لـ Google) | عنوان Kept |
| النسخ الاحتياطية | نسخ Home Assistant الاحتياطية؛ خارج الجهاز عبر [مواقع النسخ الاحتياطي](https://www.home-assistant.io/common-tasks/general/backups/) | نسخ Kept الاحتياطية الليلية: restic إلى مجلد، أو S3، أو SFTP |
| الصور والملفات | في بيانات التطبيق | على القرص، أو S3 |

- **التطبيق:** تشغّل بالفعل نظام Home Assistant OS.
- **Compose أو Kubernetes:** أي شيء آخر؛ أو الصور والملفات على S3؛ أو نسخ Kept الاحتياطية الخاصة خارج الجهاز.

## التثبيت

<HomeAssistantButton />

1. **الإعدادات → التطبيقات → تثبيت تطبيق → ⋮ → المستودعات**، أضف `https://github.com/keptinventory/kept` (أو استخدم الزر أعلاه).
2. ابحث عن **Kept**، ثم **تثبيت**، ثم **ابدأ**.
3. **افتح واجهة الويب**. يفتح Kept داخل Home Assistant، وفي الشريط الجانبي أيضًا.

| ما تحتاجه | |
|---|---|
| Home Assistant OS | تحتاج التطبيقات إلى المشرف: ليست Home Assistant Container أو Core. المشرف 2026.10.4 أو أحدث |
| `aarch64` أو `amd64` | راسبيري باي 4 أو 5 على 64 بت، أو كمبيوتر مصغر، أو آلة افتراضية |
| 4 غيغابايت من الذاكرة | يعمل 2 غيغابايت مع تطبيقات قليلة أخرى؛ Kept مع قاعدة بياناته يستهلك حوالي 250–320 ميغابايت في وضع الخمول |

## التشغيل الأول

- **مسؤول Home Assistant** الذي يفتح Kept من Home Assistant يضبطه دون رمز (المشرف 2026.10.4 أو أحدث؛ قبل ذلك يلزم الرمز).
- أي شخص آخر يكتب رمز الإعداد من علامة تبويب **السجل** في التطبيق (`KEPT SETUP CODE: XXX-XXX`).
- لدى Kept حساباته الخاصة. يسجل الأشخاص الدخول إلى Kept مرة واحدة، أيضًا داخل Home Assistant؛ لا يحتاج أفراد الأسرة إلى أن يكونوا مسؤولين في Home Assistant لاستخدامه من الشريط الجانبي.

## عنوان Kept

داخل Home Assistant، يفتح Kept من الشريط الجانبي. الهواتف، والملصقات المطبوعة برمز QR، وروابط البريد، وتطبيقات التكامل والذكاء الاصطناعي تحتاج إلى عنوان يعمل خارج جلسة Home Assistant، لذا يخدم التطبيق Kept أيضًا على **المنفذ ٨٠٨٠**. تُسمّي علامة تبويب **السجل** عنوانه، على سبيل المثال `Kept is at http://homeassistant.local:8080`.

| الخيار | ماذا |
|---|---|
| عنوان Kept | ضعه عندما لا يُحلّل `homeassistant.local` على شبكتك، أو تغير المنفذ. `http(s)://host[:port]`, بدون مسار. |
| https على منفذ Kept | يخدم المنفذ عبر https بشهادة Home Assistant من `/ssl` (من تطبيقات DuckDNS أو Let's Encrypt). أعد تشغيل التطبيق بعد تجديد الشهادة. |
| HSTS | `on` بشكل افتراضي. `off` عندما يكون Home Assistant نفسه، أو تطبيق آخر على ذلك المضيف، على http عادي: يغطي HSTS في Kept اسم المضيف على كل المنافذ، بما في ذلك 8123 ([HSTS](/ar/install/reverse-proxy/#hsts)). |
| مدة تسجيل الدخول عبر http | فارغ: 12 ساعة، لا يُجدّد. أيام يستمر تسجيل الدخول عبر http عادي، من 1 إلى 30، يُجدّد عند الاستخدام. لا تأثير عند تفعيل https؛ التكلفة في [البقاء على شبكتك](/ar/install/home-network/#البقاء-على-شبكتك). |
| عناوين إضافية | عناوين أخرى يجيب عليها هذا Kept، مفصولة بفواصل، مثل `http://192.0.2.20:8080`. فارغ: واحد. تُضاف إلى عناوين Home Assistant الخاصة، وليس بدلاً منها ([عنوان واحد أو أكثر](/ar/install/home-network/#أكثر-من-عنوان-واحد)). |
| البريد الصادر | رابط `smtps://`: روابط تسجيل الدخول، الدعوات والتذكيرات عبر البريد. |
| OIDC، Google | تسجيل الدخول مع مزوّد الهوية الخاص بك أو مع Google. فارغ: متوقف. |
| خادم Apprise | خادم واجهة برمجة تطبيقات Apprise لقنوات الإشعارات في Apprise. فارغ: لا شيء. |
| التسجيل | `true` أو `false` يقفلها مفتوحة أو مغلقة؛ غير مضبط، يقرر مسؤول. |
| حد الرفع (ميجابايت) | من ١ إلى ٢٠٤٨؛ الافتراضي ٢٥. |

يرسل مزوّد الخدمة الأشخاص إلى عنوان Kept الخاص، أبدًا إلى Home Assistant. عنوان إعادة التوجيه للتسجيل: `<Kept's address>/api/v1/auth/callback/oidc` لـ OIDC، `<Kept's address>/api/v1/auth/callback/google` لـ Google. تطبع علامة تبويب **السجل** ذلك بمجرد ضبط تسجيل الدخول. داخل Home Assistant، يفتح **تسجيل الدخول باستخدام …** عنوان Kept في علامة تبويب جديدة.

يرفض Google عنوان إعادة توجيه على http، أو على اسم `.local`، أو على عنوان IP ([قواعد Google](https://developers.google.com/identity/protocols/oauth2/web-server#uri-validation)): اضبط **عنوان Kept** على https مع اسم نطاق عام، على سبيل المثال اسم DuckDNS مع **https على منفذ Kept**. تحذّر علامة تبويب **السجل** عندما لن ينجح.

إيقاف المنفذ ٨٠٨٠ (التكوين → الشبكة) يترك الشريط الجانبي فقط: لا تفتح الملصقات وتطبيق الهاتف بعد ذلك.

## ما يحتاج https

| | http عادي | https |
|---|---|---|
| الأشياء، الأماكن، البحث، التسميات، الصور من ملف | نعم | نعم |
| تكامل Kept، مُعدًّا من التطبيق | نعم | نعم |
| رموز شخصية (السكربتات)، إظهار الأسرار، عمليات التصدير | لا | نعم |
| مفاتيح المرور، الكاميرا، تثبيت تطبيق الهاتف، الإشعارات الفورية | لا | نعم |

داخل Home Assistant، يُحسب Kept على أنه https فقط عندما يُخدم Home Assistant نفسه عبر https. يجب أن يرسل وكيل أمام Home Assistant ينهي TLS `X-Forwarded-Proto: https`، أو يرى Kept http عاديًا. مفاتيح المرور تابعة لعنوان Kept الخاص: سجّل الدخول بواحدة هناك. مزيد على [الشبكة المنزلية](/ar/install/home-network/).

## النسخ الاحتياطية والتحديثات

- **النسخ الاحتياطية:** تشمل نسخ Home Assistant الاحتياطية Kept: قاعدة البيانات كنسخة احتياطية، الصور، الملفات ومفاتيح Kept. استمر في تفعيل تشفير نسخ Home Assistant الاحتياطية. تعيد الاستعادة Kept؛ يأخذ التشغيل الأول بعد الاستعادة وقتًا أطول بعض الشيء.
- **نسخة احتياطية بينما Kept متوقف** تحتفظ بالنسخة التي كتبها Kept عند آخر توقف سليم: يطلب Home Assistant من تطبيق يعمل فقط نسخة جديدة. بعد تعطل، شغّل Kept قبل النسخ الاحتياطي.
- **نسخ Kept الاحتياطية الخاصة** ليست في التطبيق: تحتاج إلى تسجيل دخول مالك قاعدة البيانات، الذي يحتفظ به التطبيق من الخادم العامل. الإدارة → النسخ الاحتياطية يذكر ذلك ويرتبط بنسخ Home Assistant الاحتياطية.
- **خارج الجهاز:** أضف مشاركة شبكة أو موقعًا سحابيًا في إعدادات نسخ Home Assistant الاحتياطية ([نسخ Home Assistant الاحتياطية](https://www.home-assistant.io/common-tasks/general/backups/)).
- **التحديثات:** إصدار التطبيق هو إصدار Kept. يحتفظ التحديث ببيانات Kept ويحدث قاعدة بياناتته عند التشغيل. شغّل **احتفظ بنسخة احتياطية من الإصدار الأخير** في مربع حوار التحديث في Home Assistant: نسخة Kept الاحتياطية الخاصة قبل التحديث متوقفة في التطبيق.

## التكامل

هذا التطبيق يشغّل Kept؛ التكامل منفصل يجلبه إلى Home Assistant ([التطبيق والتكامل](/ar/users/home-assistant/#التطبيق-والتكامل)).

ثبّت [التكامل الخاص بـ Kept](/ar/users/home-assistant/) عبر HACS وأعد تشغيل Home Assistant: يظهر Kept مكتشفًا في **الإعدادات → الأجهزة والخدمات**. أضفه، ثم اسمح له في Kept (**الإعدادات → الربط**). لا رمز لتنسخه ولا حاجة إلى https: يتواصل Kept وHome Assistant عبر الشبكة الداخلية لـ Home Assistant.
