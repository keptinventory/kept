## Qualcosa non funziona?

- **Il container continua a riavviarsi.** Leggi il suo log: `docker compose logs kept`. Kept
  controlla le sue impostazioni prima di partire e si ferma con una riga che nomina il primo
  problema, come `kept: invalid environment: KEPT_PUBLIC_URL` (esegui
  `docker compose run --rm init`). Se `docker compose up -d` si ferma a `bootstrap`,
  `docker compose logs bootstrap` dice perché. Con meno di 1 GB di memoria, un backup può
  esaurirla e Docker riavvia Kept ([cosa serve](/it/install/hardware/)).
  [Altro](/it/admin/troubleshooting/#kept-si-ferma-allavvio-con-kept-invalid-environment--o-unaltra-riga-kept)
- **La porta è occupata.** Kept usa la porta 8080 dell’host. Esegui di nuovo
  `docker compose run --rm init` con un indirizzo `http://` su una porta libera: scrive
  l’indirizzo e la porta (`KEPT_HTTP_PORT`) in `.env`. Poi `docker compose up -d`. Nell’app di
  Home Assistant, cambia la porta in **Configurazione → Rete** e imposta **Indirizzo di Kept** di
  conseguenza.
  [Altro](/it/install/compose/#1-scrivi-env)
- **Permesso negato.** Kept gira come utente 10001 con un filesystem in sola lettura, quindi una
  cartella che ci monti, come una directory di backup, deve appartenere all’uid 10001. `init`
  scrive `.env` nella cartella da cui lo esegui: eseguilo in una cartella tua.
  [Altro](/it/admin/troubleshooting/#i-backup-non-partono-o-si-attiva-lallarme-backup-obsoleto)
- **Gli altri dispositivi non lo aprono.** `localhost` si apre solo su questa macchina. Usa un nome
  che gli altri dispositivi trovano, impostato nel DNS del router o nel file hosts di ogni
  dispositivo, ed esegui di nuovo `init` con quello. Se Kept dice «Questo Kept è configurato per
  *indirizzo*. Aprilo lì.», aprilo esattamente a quell’indirizzo, oppure aggiungi l’altro in
  `KEPT_EXTRA_ADDRESSES` ([più di un indirizzo](/it/install/home-network/#più-di-un-indirizzo)).
  [Altro](/it/admin/troubleshooting/#questo-kept-è-configurato-per--oppure-la-richiesta-non-proveniva-da-questo-sito)
- **Un 502 dal reverse proxy.** Kept parla HTTP semplice sulla porta 8080: punta il proxy a
  `http://`, non `https://`, su quella porta
  ([dietro un reverse proxy](/it/install/reverse-proxy/)). Kept parte solo quando `migrate` ha
  finito; se è fallito, `docker compose logs migrate` dice perché.
  [Altro](/it/admin/troubleshooting/#kept-non-si-avvia-dopo-un-aggiornamento-e-migrate-è-terminato-con-un-errore)

Tutto il resto: [Risoluzione dei problemi](/it/admin/troubleshooting/).

## Andare oltre

- **HTTPS:** la fotocamera, l’installazione dell’app, le notifiche push e la posizione ne hanno
  bisogno. [Metti Kept su HTTPS](/it/install/https/), oppure
  [Kept su una rete di casa](/it/install/home-network/) per cosa funziona senza.
- **L’assistente:** chiedi a parole semplici, con il tuo fornitore di IA; Kept funziona anche
  senza. [Fornitori di IA](/it/users/ai-providers/), e
  [Collega un client AI (MCP)](/it/users/mcp-clients/).
- **Backup:** ogni notte e cifrati, verso una directory, S3 o SFTP. [Backup](/it/admin/backups/).
- **Posta:** reimpostazione delle password, inviti e promemoria per posta, con `KEPT_SMTP_URL` e
  `KEPT_SMTP_FROM`. [Posta, push e il feed del calendario](/it/admin/notifications/).
- **Home Assistant:** l’integrazione porta ciò che è in scadenza nelle dashboard e nelle
  automazioni. [Home Assistant](/it/users/home-assistant/).

## Aggiornamenti

- **Docker Compose:** imposta la nuova release in `KEPT_IMAGE` di `.env`, poi:

  <Code code={commands.compose.update} lang="sh" />

  Una release che cambia `compose.yaml` lo dice nelle sue note: scarica il suo file sopra il tuo.
- **Dal codice sorgente:**

  <Code code={commands.source.update} lang="sh" />

- **Kubernetes:** ogni release pubblica un chart con la stessa versione, e le sue migrazioni girano
  in un Job prima che la nuova versione serva.
- **Home Assistant:** Home Assistant propone l’aggiornamento. Attiva
  **Mantieni il backup dell'ultima versione** nella sua finestra di aggiornamento.
- **Unraid:** la scheda **Docker** propone l’aggiornamento: **apply update**.

Con una destinazione di backup impostata, Kept fa uno snapshot prima di migrare.
[Aggiornamenti e rollback](/it/admin/upgrades/).
