description: Eine Box und alles darin verleihen, jedes Teil mit eigener Aufzeichnung. Jedes Teil einzeln zurückbringen, im Zustand, in dem es zurückkam, oder als verloren markieren. Ein Set merkt sich, was darin sein sollte.

Verleihst du eine Box mit zwölf Teilen darin, und kehrt eines nicht zurück oder kommt kaputt zurück: jedes Teil behält seine eigene Aufzeichnung, wer es hatte, wann und was passiert ist. Nichts geht verloren.

## Eine Box oder ein Set verleihen

**Verleihen** an einer Box funktioniert wie bei allem anderen: wem es geht, wann es zurück sein muss, in welchem Zustand es rausgeht, eine Notiz und Fotos. Es ist eine **Übergabe**, mit einer Zeile für die Box und einer für jedes Teil darin, bis ganz nach unten, jedes erinnert sich, wo es lag („in Camera bag › Lens pouch“).

- Etwas darin, das bereits verliehen, in Reparatur oder nicht mehr in Gebrauch ist, bleibt hier; Kept sagt das.
- Ein Set listet auch seine **Teile nicht im Set** („Ersatzakku ist im Wohnzimmer“): klicke die an, die du auch verleihen willst.
- Nichts bewegt sich: jedes Teil zeigt **Mit Sam (in Camera bag) seit 3. Okt.**.
- **Rückgängig** nimmt die ganze Übergabe für 7 Tage zurück, solange sich daran nichts geändert hat.

Kept erinnert dich zwei Tage vorher, dass es zurück sein muss, und wenn es überfällig ist. Es schreibt ihnen nie.

## Während es verliehen ist

Jedes Teil kann nicht an jemand anderen verliehen werden. Es zu verschieben, in den Papierkorb zu legen oder etwas Neues in die ausgeliehene Box zu legen **fragt zuerst** („Das ist bei Sam: erst als zurückgegeben markieren, oder weitermachen?“). Nichts ändert sich ohne dass du es sagst.

## Zurückgeben

**Alles als zurückgegeben markieren** (auf der Box oder auf der Seite der Person) zeigt jedes noch ausgeliehene Teil, jedes als **Zurück** angehakt. Für jedes Teil wähle:

| Wahl | Was passiert |
|---|---|
| Zurück | Es ist zurück, wo es war; füge den Zustand hinzu, in dem es zurückgekommen ist |
| Beschädigt | Gleiches, mit einer Notiz und **Seinen Zustand aktualisieren** |
| Nicht zurückgegeben | Es bleibt bei ihnen; Erinnerungen laufen weiter |
| Verloren | Seine Zeile schließt als verloren, und das Teil ist als verloren markiert, nie gelöscht |
| Wie viele zurückkamen (eine Menge) | Der Rest bleibt auf eigener Zeile ausgeliehen |

Die Übergabe sagt dann „11 von 12 zurückgekommen“. **Rückgängig** setzt jede Zeile zurück, wie sie war. Ein nicht zurückgegebenes Teil wird später von seiner eigenen Seite geregelt: **Als zurückgegeben markieren** oder **Verloren**.

## Wo es angezeigt wird

- **Verleih-Tab eines Teils**: jede Ausleihe, mit wem, womit es sonst rausging, beide Notizen und beide Zustände, und wie es endete.
- **Seite der Person**: was sie noch hat, gruppiert nach Übergabe („3 Teile mit Camera bag“).
- **Verleih-Tab einer Box**: ihre Übergaben und wie viele zurück kamen.
- **Verlauf**: „Camera bag an Sam verliehen“, „Zurückgekommen von Sam, kaputt“, „Von Sam verloren“.

## Sets

Ein **Gesetzt** ist ein Behälter mit einer Teileliste: was darin sein sollte. Ein Teil herausbewegen, verleihen oder verlieren, und das Set weiß immer noch Bescheid.

- **Teile → Zu einem Set machen** auf einem Behälter: sein Inhalt wird als Teile angehakt; mehr über Suche hinzufügen. Ein Teil gehört zu höchstens einem Set, am Standort des Sets.
- Der **Teile**-Tab sagt **Erledigen**, „2 Teile nicht im Set“ oder **Mit Sam seit 3. Okt.**, und jedes Teil: Im Set, Sonstwo (mit **Zurücklegen**), Vermisst, Bei jemandem, oder Im Papierkorb.
- **Dieses Set prüfen** zählt es mit einer [Scan-Session](/de/users/scanning-sessions/): ihre Liste sind die Teile, egal wo sie sind. Es erscheint, solange Zählungen am Standort eingeschaltet sind.
- **Teile bearbeiten** und **Kein Set mehr** können für 7 Tage rückgängig gemacht werden.
- Suche und Listen filtern nach **Sets** und **Unvollständige Sets**.

## Wer was darf

| | Besitzer, Admin, Mitglied | Betrachter |
|---|---|---|
| Übergaben, Zeilen, Teile eines Sets sehen | ✓ | ✓ |
| Verleihen, zurückgeben, als verloren markieren | ✓ (Verleihen an; Rückgabe funktioniert auch, wenn es aus ist) | — |
| Ein Set machen, Teile bearbeiten, auflösen | ✓ | — |
| Ein Set prüfen | ✓ | Eine Prüfung: nichts gespeichert |

Verleihen und Zurückgeben brauchen eine Verbindung. Offline wird der Status angezeigt („bei Sam“), und eine Set-Prüfung funktioniert wie jede Zählung. Ein Kept-Export enthält Übergaben, ihre Zeilen und Sets mit dem Standort.
