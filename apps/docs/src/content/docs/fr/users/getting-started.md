title: Prise en main
description: Le court chemin depuis rien jusqu'à votre premier objet dans Kept, avec un lien vers la page complète pour chaque étape.
---

Le court chemin, une étape par ligne. Chaque étape renvoie à la page détaillée de cette étape.

1. **Installez-le.** Docker avec le plugin Compose ; testé sur 1 Go de RAM et un cœur de CPU.
   Téléchargez `compose.yaml`, puis `docker compose run --rm init` (il vous demande l'adresse à laquelle vous ouvrirez Kept et il écrit le fichier `.env`) et `docker compose up -d`. Aucune copie du dépôt n'est nécessaire et aucun mot de passe à créer. [Installation avec Docker Compose](/fr/install/compose/)
2. **Réclamez le serveur.** Ouvrez l'adresse, tapez le code `init` affiché, puis créez le premier compte : il devient l'administrateur de l'instance.
   [Réclamez le serveur](/fr/users/first-run/#1-réclamer-le-serveur-avec-le-code-de-configuration)
3. **Conservez les clés.** Imprimez le kit de récupération et conservez-le hors du serveur.
   [Le kit de récupération](/fr/admin/recovery-kit/)
4. **Créez votre premier foyer.** Un nom, son type, ses pièces, et un préréglage pour ce qu'il suit.
   [Créez votre premier foyer](/fr/users/first-run/#3-créez-votre-premier-foyer)
5. **Ajouter un objet.** **Capturez** sur un téléphone, ou **Ajouter ici** sur une pièce ou une boîte sur un ordinateur.
   [Ajoutez votre premier objet](/fr/users/first-run/#4-ajoutez-votre-premier-objet)
6. **Inviter quelqu’un.** Un lien ou un code QR avec un rôle (administrateur, membre ou visiteur) ; personne n'a besoin d'adresse e-mail.
   [Inviter des personnes](/fr/users/first-run/#5-inviter-des-personnes)
7. **Mettez-le en HTTPS** afin que les téléphones autorisent l'appareil photo, l'installation de Kept, l'utilisation hors ligne et les notifications push.
   [HTTPS](/fr/install/https/), ou [Kept sur un réseau domestique](/fr/install/home-network/) pour ce qui fonctionne sans cela
8. **Connectez l'IA** si vous le souhaitez : Kept fonctionne sans cela.
   [Fournisseurs d'IA](/fr/users/ai-providers/)

Ensuite : [Utilisation quotidienne](/fr/users/everyday-use/) pour la visite, la [FAQ](/fr/users/faq/) pour les questions fréquentes, et [Problèmes courants](/fr/users/troubleshooting/) lorsque quelque chose ne fonctionne pas.
