Щоночі кожний знімок містить **читабельну копію** кожного розташування: `index.html`, який відкриваєте в браузері, електронну таблицю (CSV) речей, мініатюри, а також квитанції та документи, на які посилаються сторінки. Це написано на той день, коли Kept не зможе працювати: сервер згорів, диск помер або Kept давно зник. Все, що потрібно:

- **restic**, програма резервного копіювання, на будь-якому комп'ютері (Windows, macOS або Linux). Її документація містить пакет або завантаження для кожної системи. Використовуйте версію 0.19.1, яку використовує Kept, або новішу.
- **Репозиторій і його пароль** з [набору відновлення](/uk/admin/recovery-kit/), а для S3-відра або SFTP-сервера — облікові дані, які набір перелічує разом із ними.
- Сама резервна копія: диск, відро або SFTP-сервер, куди її було надіслано.

## 1. Направте restic на резервну копію

Розділ резервного копіювання набору відновлення містить розташування репозиторію та пароль, а для S3 — два ключі. У терміналі:

```sh
export RESTIC_REPOSITORY='<the repository line from the kit>'
export RESTIC_PASSWORD='<the backup password from the kit>'
# S3 only:
export AWS_ACCESS_KEY_ID='<from the kit>'
export AWS_SECRET_ACCESS_KEY='<from the kit>'
```

На Windows PowerShell `$env:RESTIC_REPOSITORY = '…'` тощо. Каталогова резервна копія, скопійована на ноутбук, — це просто її шлях: папка `restic` усередині каталогу резервної копії.

## 2. Оберіть знімок

```sh
restic snapshots
```

виводить список усіх знімків із часом і мітками. Візьміть найновіший із міткою `nightly` (або `manual`); знімок із міткою `pre_upgrade` містить лише базу даних, а не читабельну копію. Запам'ятайте його ідентифікатор.

## 3. Відновіть читабельну копію

```sh
restic restore <snapshot ID> --target ./kept-readable --include /backup/readable
```

Це відновлює лише читабельну копію, а не дамп бази даних чи повнорозмірні файли, у нову папку `kept-readable`.

## 4. Відкрийте її

Відкрийте `kept-readable/backup/readable/index.html` у браузері. У ньому перелічено кожне розташування з його власником і часом створення копії; власний `index.html` кожного розташування перелічує його місця та речі з їхніми фото, даними про покупку та документами. `README.txt` поруч каже те саме.

Сторінки не потребують мережі й нічого не завантажують ззовні. CSV кожного розташування відкривається в електронній таблиці.

Копія кожного розташування — це те, що його **власник** міг бачити в Kept: гроші відображаються так, як їх бачив власник, а секретні значення (пароль Wi-Fi, який ви зберегли на роутері) ніколи в неї не потрапляють. Розташування, копія якого не вдалася того вечора, перелічено як "не включено сьогодні"; візьміть знімок до нього.

## Перегляд без відновлення

У Linux і в macOS із macFUSE команда `restic mount ./mnt` показує кожен знімок як папки, які можна відкривати на місці. Для цього потрібен FUSE, якого в Windows немає; `restore` працює скрізь.
