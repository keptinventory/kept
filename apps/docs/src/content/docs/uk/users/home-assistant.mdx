Інтеграція Kept для [Home Assistant](https://www.home-assistant.io/) показує те, що вам потрібно в кожній локації, і надсилає показники назад, наприклад показник одометра, який вже знає інтеграція автомобіля. Вона читає Kept за допомогою [персонального токена](/uk/users/mcp-clients/#створити-особистий-токен).

Інтеграція: [keptinventory/kept-homeassistant](https://github.com/keptinventory/kept-homeassistant), встановлюється за допомогою [HACS](https://hacs.xyz/) як спеціальний репозиторій.

Необов'язково: лише якщо ви вже запускаєте [Home Assistant](https://www.home-assistant.io/installation/). Без нього Kept працює так само.

## Застосунок і інтеграція

- **Застосунок** запускає Kept на Home Assistant OS ([встановіть його](/uk/install/home-assistant/)). Kept на вашому власному сервері працює так само.
- **Інтеграція** вносить Kept до Home Assistant: сенсори, календар і дії. Лише інтеграція може додавати сутності, тому застосунок не може.
- **Із застосунком нічого не треба копіювати:** Home Assistant сам знаходить застосунок Kept і просить під’єднатися; ви дозволяєте це в Kept. Без токена і без https.

## Перед початком

| Вам потрібно | Чому |
|---|---|
| **Home Assistant 2026.10 або новіше** | Інтеграцію зібрано та протестовано на ньому |
| **HACS** у Home Assistant | Він встановлює інтеграцію. [Завантажити HACS](https://hacs.xyz/docs/use/download/download/) ([що йому потрібно](https://hacs.xyz/docs/use/download/prerequisites/)) |
| **Kept 1.8.0 або новіше** | Воно додає зведення, яке читають сенсори |
| **Персональний токен** | Застосунок створює їх лише через HTTPS ([HTTPS](/uk/install/https/)); у домашній мережі через `http` зробіть його [на сервері](/uk/admin/cli/#токен-із-сервера) |
| **Home Assistant може досягти Kept** | Та сама мережа, VPN на кшталт Tailscale або публічна адреса. Перевірте: відкрийте адресу Kept із машини, на якій запущено Home Assistant |

## Що ви отримаєте

Кожна локація є пристроєм у Home Assistant:

| Сутність | Що показує |
|---|---|
| **Прострочено**, **Строк настав**, **Строк спливає** | Кількості на Головній Kept. Атрибут `items` перелічує перші 10, найтерміновіші спочатку |
| **Позичено іншим**, **Позичено в** | Відкриті позики. Лише де увімкнено Позичання |
| **Не визначено**, **Давно не бачено** | Речі, місце яких під сумнівом, або які не бачено протягом місяців локації |
| **Закінчується** | Речі нижче мінімуму. Лише де увімкнено Витратні матеріали |
| **Без місця**, Речі | Спочатку вимкнено; увімкніть їх у Home Assistant |
| **Строки** (календар) | Кожна річ зі строком, як подія на цілий день |

Кожен транспортний засіб (річ з лічильником, у розділі **Транспортні засоби**) є пристроєм у своїй локації:

| Сутність | Що показує |
|---|---|
| **Показник** | Останній показник, у км, милях або годинах |
| **Наступне обслуговування** | День, коли строк настав, або оцінка Kept за вашими показниками |
| **Наступне обслуговування при** | Показник, при якому строк настав |

Локація або транспортний засіб, додані в Kept пізніше, з'являться після перезавантаження інтеграції.

## Налаштування із застосунку

Із [застосунком Kept](/uk/install/home-assistant/) в тому самому Home Assistant не треба створювати чи копіювати токен, і https не потрібен.

1. **Встановіть** інтеграцію через HACS (крок 2 у Налаштуванні) і перезапустіть Home Assistant.
2. **Додайте її.** **Налаштування → Пристрої та сервіси** показує Kept як виявлений. Додайте його і підтвердьте.
3. **Дозвольте в Kept.** Home Assistant показує код і чекає. Відкрийте Kept (бічна панель підходить) у **Налаштування → З’єднання**: **Home Assistant просить під’єднатися** показує той самий код. **Дозволити**, відмітьте локації й виберіть, що йому можна, як для токена.
4. **Готово.** Home Assistant сам завершить і назве версію Kept і ваші локації.

Що отримує Home Assistant: звичайний особистий токен із назвою **Home Assistant**, створений вами і що діє від вашого імені, для відмічених локацій. Він іде з Kept до Home Assistant внутрішньою мережею Home Assistant і ніколи не показується на сторінці. Відкличте його в **Налаштування → З’єднання**. Запит, який ніхто не дозволить за 10 хвилин, завершується: почніть знову в Home Assistant. Kept створює токен лише тоді, коли Home Assistant його забирає: якщо Home Assistant перестане чекати раніше або Kept перезапуститься, токен не створюється.

## Налаштування

1. **Створіть токен.** У Kept, **Налаштування → З’єднання → Новий токен**. Відмітьте локації, які має бачити Home Assistant. **Лише читання** достатньо для сенсорів і календаря; **Читати та змінювати** також дозволяє діям нижче надсилати показники та позначати розклади виконаними. Застосунок створює токени лише коли Kept обслуговується через `https` ([HTTPS](/uk/install/https/)); через `http` той, хто керує сервером, створює його командою [`kept admin token create`](/uk/admin/cli/#токен-із-сервера).
2. **Встановіть.** У HACS, **⋮ → Custom repositories** ([як](https://hacs.xyz/docs/faq/custom_repositories/)): додайте `https://github.com/keptinventory/kept-homeassistant`, тип **Integration**. Встановіть **Kept** і перезапустіть Home Assistant.
3. **Додайте її.** **Налаштування → Пристрої та сервіси → Додати інтеграцію → Kept**. Введіть адресу Kept (`https://kept.example.org`) і токен. Вимкніть **Перевіряти сертифікат HTTPS** лише для самопідписаного сертифіката у вашій мережі.
4. **Перевірте.** Наступний крок назве версію вашого Kept і локації, до яких токен має доступ. **Надіслати** додає їх.

Що повідомляє налаштування, коли щось не так:

| Повідомлення | Що робити |
|---|---|
| Kept недоступний | Перевірте адресу та чи може Home Assistant досягти цього хоста |
| Це не Kept | Адреса відповідає, але чимось іншим: сторінкою проксі, іншим застосунком |
| Ця адреса перенаправляє на HTTPS | Використайте адресу `https://`, яку вона називає |
| Сертифікат HTTPS не довірений | Використайте довірений сертифікат або вимкніть перевірку для самопідписаного |
| Помилка HTTPS | Kept обслуговується через простий `http` на цьому порту: використайте `http://` |
| Kept відхилив токен | Його відкликано, термін дії сплив або його неправильно введено: створіть новий |
| Цей Kept не пропонує зведення | Оновіть Kept |

**Налаштувати** в інтеграції обирає, які локації токена показувати і як часто читати Kept (кожні 5 хвилин; від 1 до 60). Коли токен відкликано або строк його дії спливає, Home Assistant просить новий.

## На інформаційній панелі

Ідентифікатори сутностей походять із назв у Kept. Для локації **Головна** і автомобіля **Corolla**: `sensor.home_overdue`, `sensor.home_due`, `sensor.home_expiring`, `sensor.home_lent_out`, `sensor.home_low_stock`, `calendar.home_due_dates`, `sensor.corolla_reading`, `sensor.corolla_next_service`. Перевірте свої під **Налаштування → Пристрої та сервіси → Kept**.

Окрема [плиткова картка](https://www.home-assistant.io/dashboards/tile/) на кожну кількість або одна [картка сутностей](https://www.home-assistant.io/dashboards/entities/):

```yaml
type: entities
title: Kept, Home
entities:
  - sensor.home_overdue
  - sensor.home_due
  - sensor.home_expiring
  - sensor.home_lent_out
  - sensor.home_low_stock
  - sensor.corolla_next_service
```

Календар **Строки** показується на панелі **Календар** Home Assistant.

## Дії

**Kept: Log a reading** (`kept.log_reading`) надсилає показник для транспортного засобу (або лічильника за його id: `meter_id` сенсора **Показник**). Він з'являється в Kept як показник з Home Assistant. Kept відмовляє у показнику нижчому за попередній, і дія завершується помилкою з причиною Kept; стрибок, який Kept вважає малоймовірним, очікує перевірки у Вхідних.

**Kept: Mark a schedule done** (`kept.complete_schedule`) позначає розклад виконаним за день (сьогодні, у часомовій зоні локації) і записує обслуговування, з показником для розкладу за лічильником. Разове завдання після цього позначене виконаним і виходить з підрахунків; повторне позначення виконаним завершується помилкою.

Обидва потребують токена **Читати та змінювати**.

### Показник одометра автомобіля, надісланий до Kept

Коли показник одометра автомобіля стабілізується на 10 хвилин (автомобіль припарковано):

```yaml
alias: Odometer to Kept
triggers:
  - trigger: state
    entity_id: sensor.my_car_odometer
    for: "00:10:00"
conditions:
  - condition: template
    value_template: "{{ trigger.to_state.state | is_number }}"
actions:
  - action: kept.log_reading
    data:
      device_id: YOUR_KEPT_VEHICLE_DEVICE_ID
      value: "{{ trigger.to_state.state | float }}"
mode: queued
```

`sensor.my_car_odometer` — це сенсор інтеграції вашого автомобіля. У редакторі автоматизацій оберіть транспортний засіб Kept у полі **Транспортний засіб** дії, щоб заповнити `device_id`. Надішліть показник в одиницях лічильника транспортного засобу в Kept.

## Оновлення або видалення

- **Оновлення:** новий реліз показується під **Налаштування → Оновлення** (HACS додає його туди). Встановіть його і перезапустіть Home Assistant.
- **Видалення:** **Налаштування → Пристрої та сервіси → Kept → ⋮ → Видалити**, потім видаліть **Kept** у HACS і перезапустіть. Відкличте токен у Kept: **Налаштування → З’єднання**.

## Що вона читає

Кожні кілька хвилин, за токеном: `GET /api/v1/summary` (кількості по локаціях), `GET /api/v1/vehicles` і перша сторінка `GET /api/v1/agenda`. Календар читає `GET /api/v1/agenda` для днів, які показує. Дії використовують `POST /api/v1/meters/{id}/readings` та `POST /api/v1/schedules/{id}/complete`. Токен бачить лише власні локації і ніколи більше, ніж ви можете. Те саме зведення живить [віджети панелі](/uk/users/dashboards/).
